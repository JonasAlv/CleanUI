# LibDataBroker-1.1

GitHub mirror of LibDataBroker-1.1 for reliable addon packaging.

## Original Project

- **Author:** tekkub
- **CurseForge:** https://www.curseforge.com/wow/addons/libdatabroker-1-1
- **WowAce:** https://www.wowace.com/projects/libdatabroker-1-1
- **License:** All Rights Reserved

## Purpose

This mirror exists because CurseForge/WowAce SVN servers can experience outages, breaking GitHub Actions release workflows that depend on `externals` in `.pkgmeta`.

## Usage in .pkgmeta

```yaml
externals:
  Libs/LibDataBroker-1.1: https://github.com/kaldown/LibDataBroker-1.1
```

v1.1.4 (Minor version 4) - Stable since July 2009. This library is feature-complete.
